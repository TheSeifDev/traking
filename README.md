## Transactional email configuration

TrackUp sends invitation email through the server-only Resend adapter. Configure these variables in local environment settings or the Vercel project environment; never expose them through `NEXT_PUBLIC_*` variables or commit a real key.

```bash
RESEND_API_KEY=
RESEND_FROM_EMAIL=
# Optional:
RESEND_REPLY_TO=
```

`RESEND_FROM_EMAIL` must be a sender address or domain verified in the active Resend account. The invitation API reports `delivery_not_configured` when the required values are absent and only reports success after Resend accepts the request.
